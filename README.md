# Align

An iPhone app that uses AirPods Pro head-motion data to notice when your head stays tilted
forward or sideways for a while, and gently reminds you to reset. A wellness tool, not a
medical device.

**Status:** Phase 0/1 in progress. See [`docs/agents/task-board.md`](docs/agents/task-board.md)
for what is built and verified, and [`docs/agents/blockers.md`](docs/agents/blockers.md) for
open issues.
